## Five checks

Fixture: `WorkshopDecompressor/Src/Test/Modern-Addon.gma`. Put the Linux binary and the fixture in a scratch folder and run this as a file, not as a one-liner.

```sh
#!/bin/sh
set -u
cd "$HOME/gma-checks" || exit 1

python3 - <<'PY'
d = bytearray(open("Modern-Addon.gma", "rb").read())
d[len(d) - 50] ^= 0xFF
open("flip.gma", "wb").write(d)
PY
head -c 15000 Modern-Addon.gma > cut.gma

run() {
	name=$1
	shift
	rm -rf "$name"
	./fastgmad "$@" >"$name.out" 2>"$name.err"
	code=$?
	echo "=== $name exit=$code"
	echo "--- stdout"; cat "$name.out"
	echo "--- stderr"; cat "$name.err"
}

run good extract -file Modern-Addon.gma -out good
run flip extract -file flip.gma -out flip
run cut extract -file cut.gma -out cut
run strict extract --strict -file flip.gma -out strict
run noargs
find strict -type f | sort
```

Expected: 0 with a status line, 0 with `crc_mismatch: 1`, 1 with no stdout, 1 with no stdout and both files written, 2 with usage on stderr.

Do not trust `$?` in an inline `wsl.exe` command from this agent: the shell expanded it before bash ran and every case looked like 0. Use the script above, or one `wsl.exe` call per case and read `$LASTEXITCODE`.
